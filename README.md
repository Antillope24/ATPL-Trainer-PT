# ATPL Progress Trainer

Lernapp mit den Fragen aus den RWL Progress Tests: Testmodus (45 Fragen pro PT, Auswertung am Ende, 75 % Bestehensgrenze) und Karteikarten mit Wiederholung nach dem Leitner System.

Läuft als Web App im Browser und offline nach der Installation auf dem Home Bildschirm. Der Lernfortschritt wird nur auf dem eigenen Gerät gespeichert.
